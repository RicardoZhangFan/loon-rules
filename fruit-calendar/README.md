# 上海时令水果日历

Apple 日历订阅（只读、自动刷新）：

https://raw.githubusercontent.com/RicardoZhangFan/loon-rules/main/fruit-calendar/shanghai-fruit.ics

日历事件覆盖预计集中供应、性价比较好的购买时间段；事件为全天、非忙碌状态，截止日含当天。日期是经验估计，具体市场变化由每周证据核查更新。初版覆盖 2026-11-24 之后至 2028 年起始的产季（跨年可延续至 2029）。

- `seasons.json`：季节基线、当季证据、来源及价格目标（目标不是实时报价）。
- `shanghai-fruit.ics`：Apple Calendar 订阅文件。
- 维护：每周核查上海批发市场、政府/农业部门、媒体与商超公开信息；更新当季日期、供货状态和可比价格。保持 UID 不变、变更才提高 SEQUENCE，保留全年时间段和历史基线；DTEND 为排他的下一天。优先上海、江浙、本地零售以及进口货到港。不以固定日历当作实际降价事实。公开证据不足时保留预测并注明。日历不含账号、地址或个人信息。

初版核查日期：2026-11-24。
